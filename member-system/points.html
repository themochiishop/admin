💰 积分引擎

积分、会员等级、生日积分、积分过期、自动完成，从 Google 表格的 Apps Script 搬到 Cloud Functions：订单有变动才算那一张单，不再每 30 分钟读全部订单。只有店主看得到这一页。

读取中…

① 比对（上线前 / 怀疑对不上时）

用新的算法把全部订单、会员算一次，只算不写，列出和现在资料不一样的地方。会读一次全部订单、会员、绑定、积分记录，平常不用按。

② 打开 Cloud Functions 积分计算

  1. 上面「比对」没有不一样的（或你确认那些差异是对的）
  2. 在 Google 表格的 Apps Script 换上新的 member-system-sync.gs（拿掉积分计算的版本），并执行一次 msInstallSchedule
  3. 回来这里勾选确认，按「打开」：会补算每位会员的余额，并把最近 2 天同步过的订单算一次（换 Apps Script 那几分钟里进来的单不会漏）

③ 打开以后

「全量核对」= 每张单、每位会员都重新算一次并写入（取代 Apps Script 菜单的「🔧 全量核对」积分部分），偶尔用。「关闭」= 停止 Cloud Functions 积分计算（要改回 Apps Script 时用）。
